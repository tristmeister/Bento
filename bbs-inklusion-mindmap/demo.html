BBS Wesermarsch – Inklusion Mindmap WordPress Plugin Demo

v1.0 · Lokale Vorschau
So funktioniert das Widget:
  • Desktop (≥ 960 px): Interaktive Mindmap mit animierten SVG-Kurven. Klicke auf einen farbigen Knoten, um seine Unterpunkte aufzuklappen.
  • Mobile (< 960 px): Card-Navigation mit Slide-Animationen. Von Ebene zu Ebene durch Tippen navigieren, Breadcrumb oben zeigt den Pfad.
  • Einbindung in WordPress via Shortcode [bbs_mindmap] oder Elementor HTML-Widget.

WordPress-Einbindung

  • Plugin-Ordner in wp-content/plugins/ kopieren
  • Plugin im WP-Backend aktivieren
  • Shortcode [bbs_mindmap] in eine Seite einfügen oder
  • In Elementor: HTML-Widget → [bbs_mindmap]
  • Optionale Höhe: [bbs_mindmap height="700px"]

Links hinzufügen

In mindmap-data.js bei jedem Knoten das url-Feld ausfüllen, z. B.:

{ id: 'rg-1',
  label: 'Grundgesetz …',
  url: 'https://…' }

Leaf-Knoten mit URL öffnen beim Klick eine neue Seite.

Farben anpassen

Jeder Hauptzweig hat eine eigene color-Eigenschaft in mindmap-data.js. Die Farbe vererbt sich automatisch an alle Unterknoten und SVG-Linien.
